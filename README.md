# CrumbLedger

CrumbLedger is a quiet bake batch board for sourdough bakeries. Track every bake in a batch, mark loaves as finished, filter by kind or priority, and keep a bake batch selected while you move between views.

## Getting started

    npm install
    npm run dev

Useful checks:

    npm test
    npm run typecheck
    npm run build

Data is saved locally in the browser. No network or account is required.
